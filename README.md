# ربات مدیریت تسک گروه (هرادرم)

ربات تلگرامی برای هماهنگی کارهای روزانه بین دو نفر (مهرداد و فرزان) داخل گروه تلگرام. کاملاً روی **GitHub Actions** اجرا می‌شه — رایگان، بدون نیاز به سرور.

## چطور کار می‌کنه

هر ۵ دقیقه یک‌بار (کمترین فاصله‌ای که گیت‌هاب اجازه می‌ده) یک ورک‌فلو اجرا می‌شه، پیام‌های جدید گروه رو می‌خونه، دستورها رو پردازش می‌کنه، یادآوری‌های سررسید رو می‌فرسته و وضعیت تسک‌ها رو توی `data/tasks.json` ذخیره و کامیت می‌کنه.

چون یک پردازش دائمی نیست، بین فرستادن یک دستور و جواب ربات ممکنه **چند دقیقه** طول بکشه — طبیعیه.

## راه‌اندازی اولیه (یک‌بار)

1. توی صفحه‌ی ریپو برو به **Settings → Secrets and variables → Actions → New repository secret**
2. یک Secret به اسم `TELEGRAM_BOT_TOKEN` بساز و توکن ربات (`@Heradermgroupbot`) رو مقدارش بذار.
3. مطمئن شو ربات توی گروه **ادمین** هست (برای دیدن پیام‌های همه‌ی تاپیک‌ها لازمه).
4. تب **Actions** ریپو رو باز کن و مطمئن شو ورک‌فلوها فعالن (اگه سوال کرد، "I understand my workflows, go ahead and enable them" رو بزن).

همین. از این به بعد ربات هر ۵ دقیقه خودش اجرا می‌شه.

## دستورها

```
/task <ددلاین> | <شرح کار>    → تسک برای خودت می‌سازه
/assign <ددلاین> | <شرح کار>  → تسک برای طرف مقابل می‌سازه (ارجاع)
/done <شماره> [یادداشت]       → تسک رو انجام‌شده علامت می‌زنه
/tasks                        → لیست تسک‌های باز خودت
/alltasks                     → لیست همه‌ی تسک‌های باز (هر دو نفر)
/cancel <شماره>                → لغو یک تسک (فقط سازنده‌اش می‌تونه)
/help                          → همین راهنما
```

نمونه‌های ددلاین: `امروز 18:00` / `فردا` / `فردا 9` / `پس‌فردا` / `2 روز دیگر` / `3 ساعت دیگر` / `2026-08-25 14:00`

مثال:
```
/assign فردا 18:00 | تماس با تامین‌کننده و تایید موجودی
```

## یادآوری‌ها

برای هر تسک باز، ربات خودکار می‌فرسته:
- ۲۴ ساعت قبل از موعد
- ۲ ساعت قبل از موعد
- بعد از گذشتن موعد: هر ۶ ساعت یک‌بار تا وقتی که با `/done` بسته بشه

## ساختار پروژه

- `main.py` — نقطه‌ی اجرا
- `src/telegram_api.py` — ارتباط با تلگرام
- `src/commands.py` — پردازش دستورها
- `src/date_parser.py` — تشخیص ددلاین فارسی
- `src/reminders.py` — منطق یادآوری
- `data/tasks.json` — وضعیت تسک‌ها (خودکار آپدیت می‌شه)
- `data/config.json` — یوزرنیم دو نفر شرکت‌کننده
- `.github/workflows/task-bot.yml` — زمان‌بندی اجرا

## توسعه‌ی آینده

می‌شه بعداً یک لایه‌ی هوش مصنوعی (جمینای) اضافه کرد تا بشه ددلاین/شرح کار رو با متن آزاد و طبیعی نوشت، به‌جای فرمت `ددلاین | شرح`.
