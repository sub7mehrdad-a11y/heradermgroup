# ربات مدیریت تسک گروه (هرادرم)

ربات تلگرامی برای هماهنگی کارهای روزانه بین دو نفر (مهرداد و فرزان) داخل گروه تلگرام. کاملاً روی **GitHub Actions** اجرا می‌شه — رایگان، بدون نیاز به سرور.

## چطور کار می‌کنه

هر ساعت یک ورک‌فلو شروع می‌شه و **حدود ۵۰ دقیقه به تلگرام وصل می‌مونه** (long polling). به‌محض اینکه پیامی توی گروه گذاشته بشه، ربات همون لحظه بیدار می‌شه و در حد **۱-۲ ثانیه** جواب می‌ده. وضعیت تسک‌ها توی `data/tasks.json` ذخیره و به‌صورت خودکار کامیت می‌شه.

بین پایان یک اجرا و شروع اجرای بعدی چند دقیقه فاصله هست. توی این فاصله پیام‌ها **گم نمی‌شن** — تلگرام تا ۲۴ ساعت نگهشون می‌داره و اجرای بعدی همه رو پردازش می‌کنه؛ فقط جوابشون چند دقیقه دیرتر می‌آد.

> **مهم:** این ریپو باید **عمومی (public)** بمونه. سهمیه‌ی رایگان GitHub Actions برای ریپوهای خصوصی ۲۰۰۰ دقیقه در ماهه که برای اجرای دائمی کافی نیست، ولی برای ریپوهای عمومی نامحدوده. اگه ریپو خصوصی بشه، سهمیه ظرف چند روز تموم می‌شه و ربات می‌خوابه.

## راه‌اندازی اولیه (یک‌بار)

1. توی صفحه‌ی ریپو برو به **Settings → Secrets and variables → Actions → New repository secret**
2. یک Secret به اسم `TELEGRAM_BOT_TOKEN` بساز و توکن ربات (`@Heradermgroupbot`) رو مقدارش بذار.
3. همون‌جا یک Secret دیگه به اسم `GEMINI_API_KEY` بساز و کلید Gemini رو مقدارش بذار (بدون این، ربات فقط با دستورهای صریح مثل `/assign` کار می‌کنه؛ تشخیص متن آزاد فعال نمی‌شه).
4. **حالت حریم‌خصوصی ربات رو خاموش کن** — بدون این کار تلگرام پیام‌های عادی گروه رو اصلاً تحویل ربات نمی‌ده و ربات فقط دستورهای `/` رو می‌بینه:
   - توی تلگرام به [@BotFather](https://t.me/BotFather) بنویس `/setprivacy`
   - ربات `@Heradermgroupbot` رو انتخاب کن → **Disable**
   - بعدش **حتماً** ربات رو از گروه حذف و دوباره اضافه کن، وگرنه تغییر اعمال نمی‌شه.
5. ربات رو توی گروه **ادمین** کن.
6. تب **Actions** ریپو رو باز کن و مطمئن شو ورک‌فلوها فعالن.
7. هر دو نفر یک‌بار به ربات (`@Heradermgroupbot`) توی چت خصوصی پیام `/start` بفرستید — بدون این مرحله، یادآوری‌های خصوصی (پیام مستقیم) کار نمی‌کنن؛ یادآوری داخل گروه/تاپیک بدون این مرحله هم کار می‌کنه.

همین. از این به بعد ربات خودش هر ساعت بالا می‌آد و آنلاین می‌مونه.

## نوشتن تسک با متن آزاد (با هوش مصنوعی)

**قاعده ثابت: جمله رو با اسم طرف مقابل شروع کن.** هر پیامی که با اسم یکی از شما دو نفر شروع بشه، تسک حساب می‌شه و به **همون نفر** ارجاع داده می‌شه — این تشخیص با تطبیق ساده‌ی متن انجام می‌شه، نه حدس هوش مصنوعی، پس همیشه قابل پیش‌بینیه و هیچ‌وقت مسئول رو اشتباه نمی‌گیره.

> فرزان فردا ساعت ۶ عصر فاکتورهای این هفته رو بفرست

شکل‌های «فرزانه...»، «فرزان جان...»، «فرزان، ...» و «@farzan1369 ...» هم شناخته می‌شن.

هر پیام دیگه‌ای که با اسم شروع نشه، دست‌نخورده می‌مونه و ربات کاری باهاش نداره — مگر اینکه فعل امری صریحی مثل «لطفا»، «باید» یا «چک کن» داشته باشه.

ربات (با Gemini) تشخیص می‌ده این یک تسکه، مسئول/عنوان/توضیح/ددلاین رو استخراج می‌کنه و همون‌جا یک کارت تسک با دو دکمه می‌فرسته: **✅ انجام شد** و **🔁 ارجاع به نفر دیگه**.

**ذکر ددلاین اجباری نیست.** اگه بنویسی «فرزانه لطفا فاکتورهای فروش ثبت بشن» بدون هیچ زمانی، باز هم تسک ساخته می‌شه و کارتش چهار دکمه‌ی زمان (امروز / فردا / ۲ روز دیگه / یک هفته) می‌ده که با یک کلیک ددلاین تعیین بشه.

برای اینکه سهمیه‌ی رایگان Gemini سر گفتگوی عادی هدر نره، پیام‌ها اول با یک فیلتر ساده‌ی محلی سنجیده می‌شن و فقط پیامی که نشانه‌ای از سپردن کار داره (اسم نفر مقابل، لحن درخواستی، یا اشاره به زمان) به هوش مصنوعی فرستاده می‌شه. چت معمولی اصلاً هزینه‌ای نداره.

اگه مسئول تسک بعداً توی همون تاپیک بنویسه که کارش تموم شده یا بخشی از کار رو انجام داده و بقیه‌ش رو به نفر دیگه می‌سپره، ربات این رو هم خودش تشخیص می‌ده و تسک رو می‌بنده یا ارجاع می‌ده — بدون نیاز به دستور خاصی.

اگه Gemini موقتاً در دسترس نبود یا ددلاینی که نوشتید فهمیده نشد، ربات هیچ‌وقت حدس نمی‌زنه — یا سکوت می‌کنه یا ازتون می‌خواد واضح‌تر بنویسید/از دستور صریح استفاده کنید.

## دستورهای صریح (همیشه مطمئن، مستقل از هوش مصنوعی)

```
/task <ددلاین> | <شرح کار>    → تسک برای خودت می‌سازه
/assign <ددلاین> | <شرح کار>  → تسک برای طرف مقابل می‌سازه (ارجاع)
/done <شماره> [یادداشت]       → تسک رو انجام‌شده علامت می‌زنه
/handoff <شماره> | <یادداشت>  → بخشی از کار رو انجام دادی، بقیه رو با توضیح ارجاع بده
/tasks                        → لیست تسک‌های باز خودت
/alltasks                     → لیست همه‌ی تسک‌های باز (هر دو نفر)
/cancel <شماره>                → لغو یک تسک (فقط سازنده‌اش می‌تونه)
/help                          → همین راهنما
```

نمونه‌های ددلاین: `امروز 18:00` / `فردا` / `فردا 9` / `پس‌فردا` / `2 روز دیگر` / `3 ساعت دیگر` / `2026-08-25 14:00`

مثال:
```
/assign فردا 18:00 | تماس با تامین‌کننده و تایید موجودی
```

## کارت تسک و دکمه‌ها

هر تسک (چه با متن آزاد چه با دستور) به شکل یک کارت با عنوان، مسئول، ددلاین، توضیحات، وضعیت و تاریخچه‌ی ارجاع‌ها نمایش داده می‌شه، همراه با دو دکمه‌ی شیشه‌ای:
- **✅ انجام شد** — تسک رو فوراً می‌بنده
- **🔁 ارجاع به [نفر دیگه]** — تسک رو بدون یادداشت به طرف مقابل منتقل می‌کنه (برای ارجاع همراه با توضیح، از `/handoff` یا نوشتن طبیعی توی همون تاپیک استفاده کنید)

## چت خصوصی با ربات

هر تسکی که ساخته می‌شه، یک کپی از کارتش برای **مسئول اون تسک** توی چت خصوصی‌اش با ربات هم فرستاده می‌شه (به شرط اینکه یک‌بار `/start` زده باشه). یعنی لازم نیست گروه رو باز کنی تا بفهمی کار جدیدی داری.

توی همون چت خصوصی می‌تونی:
- دکمه‌ی **✅ انجام شد** یا **🔁 ارجاع** رو بزنی — کارت داخل گروه هم همون لحظه به‌روز می‌شه
- جواب کار رو با متن عادی بنویسی (مثلاً «تمومش کردم، همه ثبت شد») و ربات خودش تسک رو می‌بنده
- دستور بزنی: `/tasks`، `/done 3 توضیح`، `/handoff 3 | توضیح`

اگه چند تا تسک باز داشته باشی، ربات می‌پرسه کدوم رو می‌گی و لیستشون رو نشون می‌ده؛ کافیه شماره‌ی تسک رو اول پیامت بنویسی.

بر خلاف گروه، ربات توی چت خصوصی **هیچ‌وقت ساکت نمی‌مونه** — چون اونجا پیام مستقیماً خطاب به خودشه، همیشه یک جواب می‌ده.

## یادآوری‌ها

برای هر تسک باز، از لحظه‌ی ساخته‌شدنش، ربات هر **۶ ساعت یک‌بار** یادآوری می‌فرسته (هم توی همون تاپیک، هم پیام خصوصی به مسئول فعلی تسک اگه `/start` زده باشه) — تا وقتی که تسک با دکمه/`/done`/تشخیص هوش مصنوعی بسته بشه. این یعنی حتی قبل از رسیدن ددلاین هم هر ۶ ساعت یادآوری می‌گیرید؛ اگه خیلی زیاد بود بگید تا فاصله رو عوض کنم.

## ساختار پروژه

- `main.py` — نقطه‌ی اجرا و مسیردهی پیام‌ها/دکمه‌ها/پیام خصوصی
- `src/telegram_api.py` — ارتباط با تلگرام (پیام، ویرایش پیام، دکمه)
- `src/commands.py` — دستورهای صریح + توابع مشترک ساخت/اتمام/ارجاع تسک
- `src/ai_flow.py` — پردازش متن آزاد با Gemini
- `src/gemini_client.py` — تماس با Gemini (با retry و fallback بین دو مدل)
- `src/date_parser.py` — تشخیص ددلاین فارسی
- `src/task_card.py` — قالب‌بندی کارت تسک و دکمه‌ها
- `src/reminders.py` — منطق یادآوری (گروهی + خصوصی)
- `data/tasks.json` — وضعیت تسک‌ها و چت‌های خصوصی ثبت‌شده (خودکار آپدیت می‌شه)
- `data/config.json` — یوزرنیم دو نفر شرکت‌کننده
- `.github/workflows/task-bot.yml` — زمان‌بندی اجرا
